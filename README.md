# Humanitarian Risk Visualization (JBI100 Group 73)

Interactive Dash app to explore humanitarian risk indicators across countries. It combines a global
choropleth map with linked views for country profiles, comparisons, and correlation exploration.

## Features
- Global risk map with selectable layers (total, economic, social, infrastructure, demographic, transport)
- Country details radar chart on map click
- Compare mode: parallel plot across selected countries
- Explore correlations: PCA scatter with brushing and linking to the map
- Transport focus: top-N transport constraint ranking
- Colorblind-friendly palette toggle

## Data
The app loads `data/processed_risk_data.csv` generated by `data/preprocessing.ipynb`.

Required columns:
`Country, Economic Risk, Social Risk, Infrastructure Risk, Demographic Risk, Transport Constraint, Total Vulnerability, PC1, PC2`

If the CSV is missing, run the notebook to regenerate it.

## Project structure
- `app.py` - entry point
- `jbi100_app/main.py` - Dash layout and callbacks
- `jbi100_app/views/` - map, radar, compare, PCA, transport components
- `data/` - raw datasets, preprocessing notebook, and processed CSV

## Setup
Create and activate a virtual environment, then install dependencies:

```bash
python -m venv .venv
# Windows (PowerShell)
.\.venv\Scripts\Activate.ps1
# Windows (Command Prompt)
.\.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate

pip install -r requirements.txt
```

## Run
```bash
python app.py
```

Open http://127.0.0.1:8050/ in your browser.

## Usage tips
1) Click the hamburger menu to choose a risk layer and toggle colorblind mode.
2) Click a country on the map to open the radar details panel.
3) Use the top buttons:
   - Compare Countries: select multiple countries (map or dropdown).
   - Explore Correlations: brush the PCA plot; selections highlight on the map.
   - Transport Focus: adjust the slider to show top constrained countries.

## Troubleshooting
- `processed_risk_data.csv` not found: run `data/preprocessing.ipynb`.
- Empty map or charts: verify the CSV has the required columns and non-null data.
- Port in use: change the port in `app.py`.
